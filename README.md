# Gestión Comercial - Sistema POS

Un sistema de punto de venta (POS) y gestión de inventario de marca blanca, diseñado para ser rápido, escalable y adaptable a múltiples rubros comerciales. Desarrollado como una aplicación de escritorio nativa utilizando tecnologías web modernas.

## Características Principales
* **Punto de Venta:** Interfaz ágil para facturación y cálculo de subtotales.
* **Comprobantes Profesionales:** Generación automática de tickets en formato PDF con soporte para logotipos personalizados.
* **Control de Inventario:** Gestión de altas, bajas y modificaciones de mercadería con buscador en tiempo real.
* **Alertas Inteligentes:** Notificaciones visuales automáticas para productos con bajo stock.
* **Reportes Gerenciales:** Gráficos de rendimiento histórico y exportación de métricas comerciales a Microsoft Excel.

## Stack Tecnológico
* **Frontend:** React, Vite, Tailwind CSS, Lucide React.
* **Backend & Escritorio:** Tauri (Rust).
* **Base de Datos:** SQLite (Local).
* **Generación de Archivos:** jsPDF (Tickets), ExcelJS (Reportes).
